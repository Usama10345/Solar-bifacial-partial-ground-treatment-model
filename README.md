# Solar-bifacial-partial-ground-treatment-model
This code is written as part of a TEA. The goal was to minimize cost of reflective ground treatment in bifacial solar power plants and maximize energy gains. We noted that a lot of reflective ground treatments involve vegetation management too, and they thereby reduce the solar plant's operational cost on top of increasing the solar performance of the rear-side of the bifacial modules. That has been incorporated in the financial model. The irradiance model is based on this one: https://github.com/NatLabRockies/bifacialvf.

So do a pip install bifacialvf to use this one.
