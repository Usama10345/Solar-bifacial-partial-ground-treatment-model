# Solar-bifacial-partial-ground-treatment-model
This code is written as part of a TEA. The goal was to minimize cost of reflective ground treatment in bifacial solar power plants and maximize energy gains. Detailed energy and financial parametrics were conducted, and the codes are shared.
To properly use it, you'll have to create your own virtual environment. All the libraries and packages you need like numpy, matplotlib, openpyxl, etc are common packages you might already have. If not, they're all public.
One package that is also public but may need to be separately downloaded is bifacialvf. So do a pip install bifacialvf.
